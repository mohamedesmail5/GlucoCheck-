APTOS 2019 / Diabetic Retinopathy Dataset
==========================================

Place retinal fundus images in the corresponding grade folders:

  0/  - No DR / Pre-diabetic (Grade 0)
  1/  - Mild DR (Grade 1)
  2/  - Moderate DR (Grade 2)
  3/  - Severe DR (Grade 3)

Recommended sources:
- APTOS 2019 Blindness Detection (Kaggle)
- Diabetic Retinopathy Detection (Kaggle)
- EyePACS dataset

Supported formats: JPG, PNG, WEBP
Recommended resolution: 224x224 or higher
Minimum images per class: 500+ for best results
